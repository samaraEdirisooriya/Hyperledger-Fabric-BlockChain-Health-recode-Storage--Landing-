## Page Breakdown

### 1. index.html - Main Landing Page
**Purpose**: Primary entry point showcasing the research project
**Sections**:
- Navigation bar with logo and menu
- Hero section with animated blockchain background
- Project introduction and objectives
- Interactive tutorial preview
- Research methodology overview
- Team information (Tech Titans Group 21)
- Footer with university attribution

**Key Features**:
- Typewriter animation for main heading
- Animated blockchain network visualization
- Live tutorial preview with working examples
- Smooth scroll navigation
- Responsive design for all devices

### 2. architecture.html - Network Architecture
**Purpose**: Visualize Hyperledger Fabric network topology
**Sections**:
- Network overview with interactive diagram
- Node information display (org1hospital1, ordererNode)
- Transaction flow visualization
- Smart contract architecture
- Security and privacy mechanisms
- Performance metrics dashboard

**Key Features**:
- Interactive 3D network diagram
- Clickable nodes with detailed information
- Animated transaction flow simulation
- Real-time status indicators
- Educational tooltips and explanations

### 3. research.html - Comparative Analysis
**Purpose**: Academic comparison of blockchain platforms
**Sections**:
- Research objectives and methodology
- Comparative analysis table (Hyperledger vs Ethereum vs Corda)
- Performance benchmarks and metrics
- Use case scenarios and applications
- Security and privacy comparison
- Conclusions and recommendations

**Key Features**:
- Interactive comparison matrix
- Filterable criteria selection
- Animated charts and visualizations
- Downloadable research summary
- Academic citation formatting

### 4. tutorial.html - Interactive API Testing
**Purpose**: Hands-on blockchain interaction interface
**Sections**:
- API authentication management
- Patient registration interface
- Medical record management

- Code examples and documentation
- Error handling and troubleshooting

**Key Features**:
- Working API test interface
- Live response simulation
- Code syntax highlighting
- Request/response logging
- Interactive form validation
- Tutorial progress tracking

## Technical Implementation

### JavaScript Functionality (main.js)
- Animation controllers using Anime.js
- API simulation and mock responses
- Interactive form handling
- Data visualization with ECharts.js
- Particle systems with p5.js
- Network rendering with Pixi.js
- Scroll motion effects
- Mobile responsiveness handlers

### CSS Framework
- Tailwind CSS for utility-first styling
- Custom CSS for animations and effects
- Responsive grid layouts
- Professional color scheme implementation
- Typography and spacing system

### External Libraries Integration
- CDN-hosted libraries for optimal performance
- Fallback loading for critical dependencies
- Modular JavaScript architecture
- Error handling and graceful degradation
