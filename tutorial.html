Step 1: Authentication

First, let's authenticate with the Hyperledger Fabric network using your credentials.

API Endpoint

POST /identities/{username}/enroll

Try It Yourself

Code Example

curl -X POST https://a0jpqq5zam-a0w8nsa04l-connect.au0-aws-ws.kaleido.io/identities/doctor2/enroll \
  -H "Authorization: Basic YTB0c2s4bGNycjpBY3hzQklENFVHSl9FMGhNclIycmRKczJjUS0xMmV6c0Nyb05kQkphNVR3" \

Step 4: Query Patient Records

Retrieve medical records from the blockchain ledger.

API Endpoint

POST /query

Query Options

Query Examples

// Get specific record
{
  "headers": {
    "type": "SendTransaction",
    "signer": "doctor1",
    "channel": "default-channel",
    "chaincode": "health_record_storage"
  },
  "func": "GetRecord",
  "args": ["P002", "BloodPressure"],
  "init": false
}
// Get all records
{
  "headers": {
    "type": "SendTransaction",
    "signer": "doctor1",
    "channel": "default-channel",
    "chaincode": "health_record_storage"
  },
  "func": "GetAllRecords",
  "args": ["P002"],
  "init": false
}
